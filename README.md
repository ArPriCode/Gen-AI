## 🧭 About This Repository

This repository is a **complete Generative AI learning path** curated from the Newton School / NST course. It covers everything from classical ML foundations to cutting-edge topics like multi-agent orchestration, fine-tuning LLMs, and building production-ready AI pipelines.

**Who is this for?**
- 🎓 Students starting their Gen-AI journey
- 💼 Developers transitioning into AI/ML
- 🔬 Practitioners looking for structured revision material
- 🏗️ Engineers building LLM-powered products

## 🚀 Getting Started

### Clone the Repository

```bash
# Clone via HTTPS
git clone https://github.com/ArPriCode/Gen-AI.git

# Navigate into the project
cd Gen-AI

# List all worksheets
ls Module_worksheet/
```

### Access Materials

| Resource | Link |
|----------|------|
| 📁 All Files (Google Drive) | [Open Drive Folder](https://drive.google.com/drive/folders/1bh6Kx_KDRv9fMOc008vh1h_WuTpeMfd-) |

### Prerequisites

```bash
# Python 3.9+
python --version

# Recommended packages for hands-on work
pip install openai langchain transformers torch sentence-transformers chromadb python-dotenv

# For n8n (No-Code Agents)
# Visit: https://docs.n8n.io/getting-started/installation/
npx n8n
```

## 🤝 Contributing

Contributions are welcome! Here's how to get started:

```bash
# 1. Fork the repository
# Click "Fork" on GitHub → https://github.com/ArPriCode/Gen-AI/fork

# 2. Clone your fork
git clone https://github.com/<your-username>/Gen-AI.git

# 3. Create a feature branch
git checkout -b feature/add-new-module

# 4. Make your changes and commit
git add .
git commit -m "feat: add notes for Module X - Topic"

# 5. Push and open a Pull Request
git push origin feature/add-new-module
```

**Contribution ideas:**
- 📓 Add Jupyter notebooks for each module
- 📝 Improve module summaries or add notes
- 🔗 Add links to relevant papers, blogs, or videos
- 🐛 Fix broken links or typos
